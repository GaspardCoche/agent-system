Introducing Claude Opus 5.5

Anthropic

Anthropic lance Claude Opus 5.5, présenté comme le modèle le plus fort en coding agentique et en travail de connaissance, pour un coût d'exécution 40% inférieur à Opus 5 sur des charges typiques. Le lancement s'accompagne d'une famille complète : Sonnet 5.5 (30%+ plus rapide, jusqu'à 30% moins cher) et Haiku 5.5 (le petit modèle le plus rapide, taillé pour le volume, les subagents et le browser use). Pour un praticien qui construit avec Claude Code et des agents GitHub Actions, c'est une double bonne nouvelle : meilleure qualité de raisonnement agentique ET baisse structurelle du coût au token. La hiérarchie Opus/Sonnet/Haiku permet désormais de router chaque tâche vers le bon rapport capacité/prix — Haiku pour les subagents à fort volume, Opus pour l'orchestration complexe. À surveiller : l'impact réel sur les marges de vos pipelines d'enrichissement et de scoring ICP.
