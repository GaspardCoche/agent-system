Claude Code's new Mods system lets developers rewrite the AI coding tool from the inside

The Decoder

Anthropic ajoute un système de « Mods » à Claude Code : un middleware qui s'exécute directement dans l'outil. En JavaScript ou TypeScript, les développeurs peuvent remodeler l'interface et le comportement — ajouter des panneaux custom, intercepter des appels d'outils, câbler de nouvelles commandes. C'est un virage d'un assistant de code vers une plateforme programmable que chaque équipe adapte à ses propres workflows. Le hot-reload en session raccourcit drastiquement la boucle de feedback pour builder ses propres intégrations. Combiné aux serveurs MCP, cela fait de Claude Code un véritable socle d'automatisation extensible.
