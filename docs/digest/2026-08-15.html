Claude Code assure désormais la maintenance quotidienne des logiciels d'Anthropic, avec 46 % de merge

The Decoder

Anthropic teste Claude Code comme mainteneur autonome de ses propres applications : fuzzing de crashs, suppression de code mort, corrections de routine. En quelques semaines, l'agent a ouvert 388 pull requests, dont 46 % ont été mergées après revue humaine. Boris Cherny, l'inventeur de Claude Code, y voit un « premier signe » d'un travail d'ingénierie réellement délégué à la machine. Le taux de merge encore inférieur à un sur deux montre que la supervision humaine reste indispensable, mais la boucle « agent ouvre la PR → humain valide » devient un mode de travail concret, pas une démo. C'est exactement le pattern qu'un builder d'agents GitHub Actions peut répliquer chez lui dès aujourd'hui.
