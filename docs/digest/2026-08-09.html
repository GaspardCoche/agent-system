💻 Code & Dev

Auto Mode devient le réglage par défaut de Claude Code pour les plans Pro, Max et Team

Simon Willison

À partir du 14 août, Anthropic active l'Auto Mode par défaut dans Claude Code pour les nouvelles sessions des plans Pro, Max et Team. Le pari repose sur la confiance : selon les données relayées par The Decoder, le classifieur d'Auto Mode intercepte 89 % des commandes dangereuses, contre seulement 13,6 % pour les relecteurs humains. Concrètement, l'outil de coding agentique le plus utilisé cesse de solliciter une approbation manuelle à chaque étape et arbitre lui-même le risque. Pour les équipes qui exécutent des agents en continu, c'est un gain de vélocité majeur, mais aussi un transfert de responsabilité vers un modèle de sécurité automatisé qu'il faudra auditer. Le changement redéfinit l'équilibre entre autonomie et contrôle dans les pipelines de développement assistés par IA.
