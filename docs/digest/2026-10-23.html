Introducing Claude Opus 5.5 (avec Haiku 5.5 et Sonnet 5.5)

Anthropic

Anthropic lance Claude Opus 5.5, son nouveau modèle phare orienté coding agentique et travail de connaissance, avec un coût d'exécution 40% inférieur à Opus 5 sur les charges typiques. Le lancement s'accompagne de Haiku 5.5 — le petit modèle le plus rapide, pensé pour le volume (résumés, subagents, usage navigateur) — et de Sonnet 5.5, 30%+ plus rapide et jusqu'à 30% moins cher. Pour une équipe qui construit chaque jour avec Claude Code et des agents GitHub Actions, c'est une baisse directe du coût au token sur les trois paliers de la gamme. La combinaison vitesse + prix rend enfin viables les architectures multi-agents (un gros modèle qui orchestre, des Haiku en subagents) qui tournaient trop cher en continu. À surveiller : les benchmarks agentiques réels et la disponibilité API / Bedrock / Vertex.
