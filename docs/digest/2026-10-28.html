Anthropic lance Claude Opus 5.5 (et Sonnet 5.5 + Haiku 5.5)

Anthropic

Anthropic a dévoilé Claude Opus 5.5, présenté comme son meilleur modèle pour le coding agentique et le travail de connaissance, avec un coût d'exécution environ 40 % inférieur à Opus 5 sur les charges typiques. Le lancement s'accompagne de Sonnet 5.5 (30 %+ plus rapide, jusqu'à 30 % moins cher) et de Haiku 5.5, pensé pour les tâches à haut volume comme le résumé, les sous-agents et l'usage du navigateur. Anthropic met en avant la Claude Platform et une séparation nette entre le cerveau (le modèle) et les mains (outils et agents) pour fiabiliser les agents en production. Pour un stack bâti sur Claude Code, MCP et des agents GitHub Actions, c'est une baisse de coût immédiate doublée d'un gain de fiabilité sur les workflows agentiques.
