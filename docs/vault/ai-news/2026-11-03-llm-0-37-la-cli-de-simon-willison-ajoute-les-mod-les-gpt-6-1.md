# llm 0.37 : la CLI de Simon Willison ajoute les modèles gpt-6.1 et la commande openai endpoint add

**Source:** [Simon Willison](https://simonwillison.net/2026/Nov/2/llm/) | **Categorie:** Code & Dev | **Importance:** must_read

Simon Willison publie llm 0.37, deux mois de fonctionnalités accumulées pour son outil CLI et sa librairie Python. Ajout des modèles gpt-6.1-sol et gpt-6.1-terra, plus une commande `llm openai endpoint add` pour brancher facilement des endpoints compatibles OpenAI. Pour un workflow local RAG et des scripts d'enrichissement, c'est l'outil idéal pour piloter plusieurs modèles depuis le terminal.
