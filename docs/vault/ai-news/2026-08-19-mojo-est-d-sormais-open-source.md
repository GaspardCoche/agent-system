# Mojo🔥 est désormais open source

**Source:** [Simon Willison](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) | **Categorie:** Open Source | **Importance:** must_read

Après une promesse d'open source datant de mai 2023, Modular publie enfin le compilateur et la toolchain de Mojo sous licence Apache 2, une semaine après sa 1.0. Le langage, pensé pour marier la simplicité de Python et la performance système, devient enfin auditable et extensible par la communauté. Une étape clé pour l'infra IA haute performance.
