# Introducing Claude Opus 5.5

**Source:** [Anthropic](https://www.anthropic.com/news) | **Categorie:** Modeles | **Importance:** must_read (top story)

Anthropic lance Claude Opus 5.5, son nouveau modèle phare qui prend la tête sur le codage agentique et le travail de connaissance, tout en coûtant 40 % de moins à exécuter qu'Opus 5 sur les charges typiques. Le gain combiné performance/prix réduit directement le coût des agents de long-cours et des pipelines de code autonomes. Pour les équipes qui orchestrent des agents via Claude Code, GitHub Actions ou des serveurs MCP, cela signifie des boucles d'exécution plus longues et plus fiables sans explosion de la facture. Anthropic complète sa gamme avec Haiku 5.5 (petit modèle rapide pour volumes élevés, sous-agents, browser use) et Sonnet 5.5, dessinant une hiérarchie claire 'brain/hands'. C'est le type de révolution silencieuse qui change l'économie des workflows agentiques dès les semaines qui viennent.
