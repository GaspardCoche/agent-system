    # Gemini API tool retrieval for efficient agent scaling

![Gemini API tool retrieval for efficient agent scaling](https://storage.googleapis.com/gweb-uniblog-publish-prod/images/Tool_retrieval_hero.width-1300.png)

    **Source:** [Google AI Blog](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/) | **Categorie:** Code & Dev | **Importance:** must_read

    Google lance en preview le Tool Retrieval dans l'API Gemini : au lieu de charger toutes les définitions d'outils dans le contexte, l'agent récupère dynamiquement celles qui sont pertinentes. Résultat, on peut donner accès à des centaines d'outils en consommant beaucoup moins de tokens. C'est une réponse directe au problème de saturation de contexte quand on branche un gros parc de serveurs MCP.
