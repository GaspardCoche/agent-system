    # Claude Code intègre une commande /design pour créer des maquettes UI dans le terminal

![Claude Code intègre une commande /design pour créer des maquettes UI dans le terminal](https://the-decoder.com/wp-content/uploads/2026/08/anthropic_claude_design.png)

    **Source:** [The Decoder](https://the-decoder.com/claude-code-gets-a-design-command-that-lets-developers-create-ui-mockups-right-in-the-terminal/) | **Categorie:** Code & Dev | **Importance:** must_read (top story)

    Anthropic ajoute une commande /design à Claude Code qui génère des maquettes d'interface (artboards) directement dans le terminal, avant même d'écrire une ligne de code. Claude lit la base de code existante et calque le style UI en place, ce qui rapproche le workflow design-to-code sans quitter l'agent. C'est un signal fort : Claude Code cesse d'être un simple générateur de code pour devenir un environnement de conception itératif. Pour un builder qui vit dans le terminal, cela raccourcit la boucle idée → mockup → implémentation et réduit les allers-retours vers Figma. La fonctionnalité renforce la stratégie d'Anthropic de faire de Claude Code la couche centrale du développement assisté.
