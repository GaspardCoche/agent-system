# Introducing Claude Fable 5.2 and Claude Mythos 5.2

**Source:** [Anthropic](https://www.anthropic.com/news) | **Categorie:** Modeles | **Importance:** must_read (top story)

Anthropic présente Claude Fable 5.2 et Claude Mythos 5.2, décrits comme ses modèles les plus capables pour le travail technique exigeant, avec un nouveau palier en coding agentique, finance et sciences. L'annonce tombe le jour même de l'IPO de l'entreprise, signal d'une cadence produit qui ne faiblit pas malgré l'événement financier. Pour un praticien qui construit avec Claude Code au quotidien, un saut de capacité sur le code agentique se traduit directement par des agents GitHub Actions plus fiables et des boucles d'auto-correction plus courtes. La famille 5.5 (Opus 5.5, Haiku 5.5) reste disponible pour les tâches à fort volume ou à faible latence, laissant le choix du bon modèle selon le coût et la complexité. À tester dès cette semaine sur un workflow réel avant de migrer les agents de production.
