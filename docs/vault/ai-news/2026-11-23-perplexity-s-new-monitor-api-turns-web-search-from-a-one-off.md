    # Perplexity's new Monitor API turns web search from a one-off query into a nonstop watchdog

![Perplexity's new Monitor API turns web search from a one-off query into a nonstop watchdog](https://the-decoder.com/wp-content/uploads/2026/06/Perplexity-Logo-Silhouette-Nano-Banana-Pro.jpg)

    **Source:** [The Decoder](https://the-decoder.com/perplexitys-new-monitor-api-turns-web-search-from-a-one-off-query-into-a-nonstop-watchdog/) | **Categorie:** Outils & Plateformes | **Importance:** must_read

    Perplexity lance une Monitor API qui interroge le web selon un calendrier et n'alerte tes agents par webhook que lorsqu'un changement pertinent survient, un modèle de décision filtrant le bruit. C'est la bascule d'une recherche ponctuelle vers une veille continue pilotée par agent.
