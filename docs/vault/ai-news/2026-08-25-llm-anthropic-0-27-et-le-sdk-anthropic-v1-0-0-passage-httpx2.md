# llm-anthropic 0.27 et le SDK Anthropic v1.0.0 (passage à httpx2)

**Source:** [Simon Willison](https://simonwillison.net/2026/Aug/24/llm-anthropic/) | **Categorie:** Code & Dev | **Importance:** must_read

Simon Willison publie llm-anthropic 0.27, aligné sur la toute nouvelle bibliothèque Python anthropic v1.0.0 qui bascule de httpx vers httpx2 — un changement majeur (OpenAI a fait le même saut en v3.0.0 deux semaines plus tôt). Anthropic fournit un guide de migration, que Willison a fait appliquer par Fable 5 dans Claude Code jusqu'à faire passer les tests. C'est à la fois une rupture d'API à absorber et une démonstration concrète d'upgrade piloté par agent.
