    # Qwen 3.8 27B est excellent, mais il a tendance à sur-réfléchir

![Qwen 3.8 27B est excellent, mais il a tendance à sur-réfléchir](https://static.simonwillison.net/static/2026/qwen-thinking-bicycle-27b.jpg)

    **Source:** [Simon Willison](https://simonwillison.net/2026/Aug/16/qwen-38-27b/) | **Categorie:** Open Source | **Importance:** must_read

    Alibaba a publié Qwen 3.8 27B, un modèle vision sous licence Apache 2, dans une taille idéale pour tourner sur un laptop correctement équipé. Simon Willison le juge excellent, avec un bémol : par défaut il « sur-raisonne » et gaspille des tokens sur des tâches simples. C'est l'un des rares poids ouverts assez capables pour un usage local sérieux sans dépendre d'une API cloud.
