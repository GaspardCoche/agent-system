# llm-anthropic 0.26

**Source:** [Simon Willison](https://simonwillison.net/2026/Aug/4/llm-anthropic/#atom-everything) | **Categorie:** Outils & Plateformes | **Importance:** must_read

Le plugin llm-anthropic 0.26 exploite LLM 0.32 pour ajouter les nouveaux modèles claude-fable-5, claude-sonnet-5 et claude-opus-5. Il expose surtout les outils côté serveur d'Anthropic — WebSearch, WebFetch, CodeExecution et AnthropicMCP — accessibles via l'interface -T de LLM ou l'argument tools= en Python. C'est un accès direct au MCP hébergé de Claude sans monter de serveur soi-même.
