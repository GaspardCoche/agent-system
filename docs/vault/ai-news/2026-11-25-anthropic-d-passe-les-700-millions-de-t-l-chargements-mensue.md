    # Anthropic dépasse les 700 millions de téléchargements mensuels du SDK MCP et étend le protocole pour des agents plus autonomes

![Anthropic dépasse les 700 millions de téléchargements mensuels du SDK MCP et étend le protocole pour des agents plus autonomes](https://the-decoder.com/wp-content/uploads/2026/11/anthropic_claude_logo.png)

    **Source:** [The Decoder](https://the-decoder.com/anthropic-tops-700-million-monthly-mcp-sdk-downloads-and-expands-the-protocol-for-more-autonomous-ai-agents/) | **Categorie:** Outils & Plateformes | **Importance:** must_read (top story)

    Deux ans après son lancement, MCP franchit les 700 millions de téléchargements mensuels, confirmant son statut de standard d'interface entre modèles et outils. Anthropic ajoute des capacités clés : tâches en arrière-plan (background tasks), questions de suivi posées à l'utilisateur et uploads de fichiers, pour que Claude travaille de façon plus indépendante sur des flux longs. Ces primitives rapprochent MCP d'un véritable runtime d'agents plutôt que d'un simple pont requête-réponse. Pour tout builder d'agents GitHub Actions ou de serveurs MCP maison, c'est un signal fort : l'écosystème se consolide et vaut la peine d'y investir maintenant. Les background tasks en particulier ouvrent la voie à des agents qui enrichissent, scorent et relancent sans supervision continue.
