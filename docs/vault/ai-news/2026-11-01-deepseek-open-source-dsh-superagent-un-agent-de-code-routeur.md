    # DeepSeek open-source dsh-superagent, un agent de code routeur-worker

![DeepSeek open-source dsh-superagent, un agent de code routeur-worker](https://www.marktechpost.com/wp-content/uploads/2026/11/WP-BLOG-BANNER-88881-scaled.png)

    **Source:** [MarkTechPost](https://www.marktechpost.com/2026/11/01/deepseek-dsh-superagent-router-worker-coding-agent/) | **Categorie:** Open Source | **Importance:** must_read

    DeepSeek publie dsh-superagent, un prototype de recherche sous licence MIT qui transforme des requêtes GitHub et Feishu en sessions de workers parallèles. Dans sa propre simulation, le temps de complétion p95 chute de 29,5 à 15,7 minutes. L'architecture routeur-worker — un routeur dispatche vers des workers spécialisés — est exactement le pattern d'orchestration multi-agents du moment.
