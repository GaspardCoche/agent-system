    # Redesigning source control at Anthropic

![Redesigning source control at Anthropic](https://static.simonwillison.net/static/2026/anthropic-merges-per-day.webp)

    **Source:** [Simon Willison](https://simonwillison.net/2026/Oct/13/redesigning-source-control-at-anthropic/) | **Categorie:** Code & Dev | **Importance:** must_read

    Anthropic décrit pourquoi et comment elle a construit une alternative maison à Git, face à l'explosion du rythme de changements de code depuis six mois (~2 500 merges/jour en mai 2026). Le constat : les outils de versioning conçus pour des humains ne tiennent plus face au volume généré par les agents de code. C'est un signal fort sur l'avenir des workflows dev à l'ère des coding agents.
