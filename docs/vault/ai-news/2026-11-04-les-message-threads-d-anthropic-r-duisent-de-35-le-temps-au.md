    # Les Message Threads d'Anthropic réduisent de 35% le temps au premier token sur les longues conversations

![Les Message Threads d'Anthropic réduisent de 35% le temps au premier token sur les longues conversations](https://the-decoder.com/wp-content/uploads/2026/08/claude_logo-1.png)

    **Source:** [The Decoder](https://the-decoder.com/anthropics-message-threads-cut-time-to-first-token-by-35-percent-for-long-conversations/) | **Categorie:** Outils & Plateformes | **Importance:** must_read

    Anthropic a publié Message Threads pour la Messages API : au lieu de renvoyer toute la conversation à chaque tour, les agents ne transmettent plus que ce qui a changé. Pour des requêtes entre 500 000 et 1 million de tokens, le temps au premier token chute d'environ 35%. C'est un changement d'API concret qui touche directement la latence et le coût des agents à long contexte.
