    # Les agents IA deviennent les premiers clients des LLM : +14x de tokens sur OpenRouter

![Les agents IA deviennent les premiers clients des LLM : +14x de tokens sur OpenRouter](https://the-decoder.com/wp-content/uploads/2026/06/tokenization-2-1200x670.png)

    **Source:** [The Decoder](https://the-decoder.com/ai-is-becoming-ais-biggest-customer-as-agentic-token-usage-jumps-14x-on-openrouter/) | **Categorie:** Outils & Plateformes | **Importance:** must_read

    Sur OpenRouter, les agents consomment plus de tokens que les humains depuis février 2025, avec une croissance de 14x contre seulement 2,8x pour l'usage humain. Point clé pour les coûts : près de 70% de la consommation des agents provient de prompts en cache, si bien que la facture réelle grimpe bien plus lentement que le volume brut. Un signal fort que l'économie des agents repose sur le caching, pas sur le nombre d'appels.
