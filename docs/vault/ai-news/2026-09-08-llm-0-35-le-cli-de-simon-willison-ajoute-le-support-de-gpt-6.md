# llm 0.35 : le CLI de Simon Willison ajoute le support de GPT-6 Astra

**Source:** [Simon Willison](https://simonwillison.net/2026/Sep/7/llm/) | **Categorie:** Code & Dev | **Importance:** must_read

La version 0.35 de l'outil open-source `llm` ajoute le modèle gpt-6-astra, accessible en une ligne de commande ou en pipe depuis le terminal. C'est l'un des moyens les plus rapides d'appeler et de comparer les modèles frontière depuis des scripts, sans SDK lourd. Idéal pour brancher un modèle dans une chaîne d'automatisation ou un pipeline de données.
