    # Gemini 3.7 Flash : le modèle workhorse le plus intelligent de Google

![Gemini 3.7 Flash : le modèle workhorse le plus intelligent de Google](https://storage.googleapis.com/gweb-uniblog-publish-prod/images/gemini-3-7-flash.width-1300.png)

    **Source:** [Google DeepMind](https://deepmind.google/blog/introducing-gemini-3-7-flash/) | **Categorie:** Modeles | **Importance:** must_read (top story)

    Google DeepMind publie Gemini 3.7 Flash à peine trois semaines après la 3.6, avec des gains substantiels sur le code et les agents. Selon les benchmarks maison, le modèle dépasse Claude Sonnet 5 et GPT-5.6 Terra tout en cassant de 50 % le prix de son prédécesseur pourtant tout récent. Cette cadence de sortie et cette agressivité tarifaire transforment le segment « workhorse » (le modèle par défaut à haut volume) en champ de bataille sur le coût par token. Pour toute stack qui route des milliers d'appels quotidiens, le calcul économique du modèle par défaut est à réévaluer dès maintenant. Le support est déjà disponible côté outillage via le plugin llm-gemini 0.33.
