    # OpenAI DevDay 2026 : Dots, GPT-6.1 Sol, Ultrafast, Decisions API et une marketplace pour 1,2 milliard d'utilisateurs

![OpenAI DevDay 2026 : Dots, GPT-6.1 Sol, Ultrafast, Decisions API et une marketplace pour 1,2 milliard d'utilisateurs](https://substackcdn.com/image/youtube/w_728,c_limit/GjN3xLDuc8o)

    Le DevDay le plus offensif d'OpenAI empile plus de 20 annonces : agents « Dots » toujours actifs, modèle GPT-6.1 Sol quasi au niveau d'Astra pour un cinquième du prix, tier Ultrafast, nouvelle Decisions API pour les décisions unitaires rapides, et une Agents API qui gère désormais le Computer Use. Surtout, ChatGPT devient une plateforme applicative : documents et slides collaboratifs, système de plugins ouvert avec automatisations MCP, intégrations Slack et Teams, et une marketplace enterprise de 32 partenaires. OpenAI revendique 1,2 milliard d'utilisateurs hebdomadaires et un run rate proche de 70 Md$. Pour un praticien, la combinaison prix-en-baisse + API agentiques + distribution intégrée redéfinit à la fois le coût unitaire des automatisations et le canal par lequel les logiciels atteignent les utilisateurs. C'est un signal clair que la couche « agent + app store » devient le terrain de bataille des 6 prochains mois.
