    # Anthropic amène Claude Cowork dans son extension Chrome, avec skills et plugins

![Anthropic amène Claude Cowork dans son extension Chrome, avec skills et plugins](https://the-decoder.com/wp-content/uploads/2025/08/ClaudeBrowsing.png)

    Claude Cowork tourne désormais directement dans le panneau latéral de l'extension Chrome d'Anthropic, avec le support des skills et des plugins. L'agent Claude passe ainsi du terminal au navigateur, au contact direct des applications web du quotidien. C'est une extension nette de l'écosystème Claude vers les tâches in-browser.
