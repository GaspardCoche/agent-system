# Claude Code prend désormais en charge AGENTS.md (v2.1.277)

**Source:** [Simon Willison](https://simonwillison.net/2026/Sep/18/thariq-shihipar/) | **Categorie:** Code & Dev | **Importance:** must_read

À partir de la version 2.1.277, si aucun CLAUDE.md n'existe dans un dossier, Claude Code cherche et utilise automatiquement un AGENTS.md. La fonctionnalité repose sur les « Claude Code mods », le futur mécanisme de personnalisation du harness, ici livré comme mod intégré. C'est un pas concret vers un standard d'instructions d'agents partagé entre outils.
