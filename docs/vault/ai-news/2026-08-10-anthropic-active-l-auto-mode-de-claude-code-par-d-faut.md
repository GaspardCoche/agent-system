    # Anthropic active l'auto mode de Claude Code par défaut

![Anthropic active l'auto mode de Claude Code par défaut](https://techcrunch.com/wp-content/uploads/2026/04/GettyImages-2269811684.jpg?w=1024)

    **Source:** [TechCrunch AI](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) | **Categorie:** Code & Dev | **Importance:** must_read (top story)

    À partir du 14 août, Anthropic active « auto mode » par défaut dans Claude Code pour les plans Pro, Max et Team, réduisant drastiquement les validations manuelles à chaque étape. Pour justifier ce pari, l'entreprise publie une éval sur 1 053 développeurs payés : lorsqu'une commande clairement dangereuse était glissée dans une session, seuls 13,6 % des humains l'ont refusée, contre 89 % d'actions bloquées par l'auto mode. Le message : pour l'injection de prompt et l'exfiltration de données, l'agent supervisé est désormais plus fiable que le relecteur humain moyen. C'est un changement de posture pour quiconque code au quotidien avec Claude Code — on passe de « valider chaque action » à « configurer et auditer les garde-fous ». La confiance affichée par Anthropic suggère que les workflows agentiques longue durée deviennent la norme opérationnelle, pas l'exception.
