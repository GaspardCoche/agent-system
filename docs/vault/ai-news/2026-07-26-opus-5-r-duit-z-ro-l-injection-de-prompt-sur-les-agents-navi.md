    # Opus 5 réduit à zéro l'injection de prompt sur les agents navigateurs

![Opus 5 réduit à zéro l'injection de prompt sur les agents navigateurs](https://the-decoder.com/wp-content/uploads/2025/11/prompt_injections_claude.png)

    **Source:** [The Decoder](https://the-decoder.com/opus-5-may-have-solved-browser-based-prompt-injection-the-biggest-security-flaw-haunting-ai-agents/) | **Categorie:** Code & Dev | **Importance:** must_read

    Combiné à Auto Mode, Opus 5 atteint un taux de succès de 0 % contre l'injection de prompt sur 129 scénarios d'agents navigateurs, contre 3,7 % sans ces couches de protection. Sur le benchmark Gray Swan, le taux de réussite des attaquants après 15 tentatives chute à 2,0 %, devant Mythos 5 et Fable 5. Si ces chiffres tiennent en production, Anthropic aurait craqué l'un des plus gros verrous de sécurité des agents, qu'OpenAI jugeait peut-être insoluble.
