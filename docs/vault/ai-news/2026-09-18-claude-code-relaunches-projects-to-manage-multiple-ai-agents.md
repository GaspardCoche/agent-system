    # Claude Code relaunches Projects to manage multiple AI agents in the cloud

![Claude Code relaunches Projects to manage multiple AI agents in the cloud](https://platform.theverge.com/wp-content/uploads/sites/2/2026/09/videoframe_18541.png?quality=90&strip=all&crop=0%2C3.4613147178592%2C100%2C93.077370564282&w=1200)

    **Source:** [The Verge AI](https://www.theverge.com/ai-artificial-intelligence/997134/anthropic-claude-code-projects) | **Categorie:** Outils & Plateformes | **Importance:** must_read (top story)

    Anthropic refond Projects dans Claude Code : un coordinateur découpe une tâche en plusieurs threads cloud qui tournent en parallèle, ouvrent leurs propres pull requests et lancent leurs tests, tout en partageant une mémoire, des objectifs et une bibliothèque d'artefacts communs. The Decoder précise que la bêta est réservée à des abonnés Pro et Max sélectionnés et vise clairement le codage autonome de bout en bout. Pour une équipe lean, cela transforme Claude Code en chef d'orchestre capable de mener plusieurs chantiers de front sans supervision continue. Le risque : la coordination entre agents multiplie la consommation de tokens et peut créer du travail redondant (cf. le débat sur la « coordination tax »). C'est la brique manquante pour transformer des workflows GitHub Actions ad hoc en une usine d'agents pilotée depuis une mémoire partagée.
