    # Les harnais sophistiqués rendent les agents de code plus chers, pas meilleurs

![Les harnais sophistiqués rendent les agents de code plus chers, pas meilleurs](https://the-decoder.com/wp-content/uploads/2026/10/harness-buys-tokens-nano-banana-pro.jpg)

    **Source:** [The Decoder](https://the-decoder.com/fancy-harnesses-make-coding-agents-more-expensive-but-not-better-study-finds/) | **Categorie:** Code & Dev | **Importance:** must_read

    Une étude contrôlée montre que changer de harnais d'agent de code (Claude Code, OpenCode, mini-SWE-agent) ne bouge quasi pas les taux de réussite, pas plus que relancer le même setup. En revanche le coût par tâche peut tripler, surtout à cause du system prompt renvoyé à chaque étape. Le message : optimise d'abord ton prompt système et le nombre de steps avant d'empiler de l'outillage.
