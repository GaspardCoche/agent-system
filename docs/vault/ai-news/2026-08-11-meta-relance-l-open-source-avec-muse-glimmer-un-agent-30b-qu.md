    # Meta relance l'open source avec Muse Glimmer, un agent 30B qui tourne en local

![Meta relance l'open source avec Muse Glimmer, un agent 30B qui tourne en local](https://the-decoder.com/wp-content/uploads/2026/07/meta_AI_logo.png)

    **Source:** [The Decoder](https://the-decoder.com/meta-returns-to-open-models-with-zuckerbergs-plan-to-out-copy-china-and-sell-compute-by-auction/) | **Categorie:** Open Source | **Importance:** must_read (top story)

    Meta relance la course aux poids ouverts avec Muse Glimmer, premier modèle de ses nouveaux Superintelligence Labs : un modèle agentique de 30 milliards de paramètres, multimodal, sous licence Apache 2.0, qui tourne sur un GPU grand public (RTX 3090, moins de 20 Go une fois compressé). Dans un essai de 6 500 mots, Zuckerberg assume une stratégie de distillation des modèles concurrents et propose un marché de compute vendu aux enchères. Pour les développeurs, cela signifie un modèle local capable de coding, function calling et usage agentique sans dépendance cloud ni fuite de données. Simon Willison, Latent Space et Hugging Face confirment tous qu'il s'agit d'un vrai retour de Meta dans l'open source, loin des licences bancales de Llama. C'est le signal d'une nouvelle vague de modèles locaux réellement exploitables en production.
