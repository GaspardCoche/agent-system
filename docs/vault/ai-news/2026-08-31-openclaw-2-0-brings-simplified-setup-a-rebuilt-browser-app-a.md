    # OpenClaw 2.0 brings simplified setup, a rebuilt browser app, and multiplayer sessions

![OpenClaw 2.0 brings simplified setup, a rebuilt browser app, and multiplayer sessions](https://the-decoder.com/wp-content/uploads/2026/08/openclaw_logo_threepart.png)

    **Source:** [The Decoder](https://the-decoder.com/openclaw-2-0-brings-simplified-setup-a-rebuilt-browser-app-and-multiplayer-sessions/) | **Categorie:** Open Source | **Importance:** must_read (top story)

    La OpenClaw Foundation publie la version 2.0 de sa plateforme d'IA open-source, sa plus grosse release à ce jour avec plus de 16 000 pull requests fusionnées. Les nouveautés majeures : des sessions cloud sur machines louées, de la collaboration temps réel (sessions multijoueurs) et une application navigateur reconstruite de zéro. Le setup est drastiquement simplifié, avec détection automatique de l'environnement. GitHub confirme en parallèle qu'OpenClaw est le projet à la croissance la plus rapide de son histoire, avec une communauté de mainteneurs qui s'organise pour sécuriser un code désormais critique. C'est un signal fort que l'agentique open-source devient une brique d'infrastructure sérieuse, et plus seulement un terrain d'expérimentation.
