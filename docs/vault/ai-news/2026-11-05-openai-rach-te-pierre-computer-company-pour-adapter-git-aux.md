    # OpenAI rachète Pierre Computer Company pour adapter Git aux agents de code

![OpenAI rachète Pierre Computer Company pour adapter Git aux agents de code](https://the-decoder.com/wp-content/uploads/2026/03/openai_logo_wall.png)

    **Source:** [The Decoder](https://the-decoder.com/openai-acquires-pierre-computer-company-to-make-git-keep-up-with-ai-coding-agents/) | **Categorie:** Code & Dev | **Importance:** must_read

    OpenAI acquiert Pierre, la startup dont les bibliothèques alimentent déjà l'agent de code Codex. Combinée au backend Git récemment lancé par OpenAI (Pando), l'opération montre la construction d'une infrastructure où développeurs et agents travaillent côte à côte sur le même dépôt. Le versioning devient un chantier stratégique dès lors que des flottes d'agents commitent en parallèle.
