    # Le changement de limites de Claude Code : une hausse sur le papier, une coupe en pratique

![Le changement de limites de Claude Code : une hausse sur le papier, une coupe en pratique](https://the-decoder.com/wp-content/uploads/2026/08/anthropic_claude.png)

    Anthropic remplace le boost temporaire de 50 % des limites hebdomadaires de Claude Code (qui expire le 14 septembre) par une hausse permanente de 25 %, soit une baisse nette d'environ 17 % en pratique. En échange, la firme promet plus de contrôle et de transparence sur la consommation. Pour les gros utilisateurs quotidiens, l'enveloppe utile se resserre malgré le discours de « hausse ».
