# LLM 0.36 : support de GPT-6 Sol/Luna et prompts mono-tour

**Source:** [Simon Willison](https://simonwillison.net/2026/Sep/22/llm/) | **Categorie:** Code & Dev | **Importance:** must_read

La CLI LLM ajoute gpt-6-sol et gpt-6-luna, et permet aux plugins de déclarer supports_conversation = False pour les modèles à un seul tour. En parallèle, llm-anthropic 0.29 ajoute le support de Claude Opus 5.5 (`llm -m claude-opus-5.5`). De quoi tester les tout nouveaux modèles depuis le terminal en une commande.
