# Introducing Claude Opus 5.5

**Source:** [Anthropic](https://www.anthropic.com/news) | **Categorie:** Modeles | **Importance:** must_read (top story)

Anthropic dévoile Claude Opus 5.5, présenté comme le modèle de référence pour le coding agentique et le travail de la connaissance, avec un coût d'exécution annoncé 40% inférieur à celui d'Opus 5 sur les charges typiques. Le lancement s'accompagne de Sonnet 5.5 (30%+ plus rapide, jusqu'à 30% moins cher) et de Haiku 5.5, le petit modèle le plus rapide, taillé pour le résumé, les sous-agents et le browser use. Cette baisse de coût sur le haut de gamme change l'économie des workflows agentiques intensifs : relancer des boucles d'auto-correction, des pipelines multi-agents ou des audits de code devient nettement plus abordable. Combinée à Haiku 5.5 pour les sous-tâches à fort volume, la gamme permet d'orchestrer des architectures "gros modèle pilote / petit modèle exécutant" sans exploser le budget. Pour un atelier bâti sur Claude Code et des agents GitHub Actions, c'est un gain direct de marge opérationnelle.
