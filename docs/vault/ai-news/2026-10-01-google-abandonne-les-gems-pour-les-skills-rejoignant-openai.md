    # Google abandonne les Gems pour les « Skills », rejoignant OpenAI et Anthropic

![Google abandonne les Gems pour les « Skills », rejoignant OpenAI et Anthropic](https://the-decoder.com/wp-content/uploads/2026/07/google_gemini-1.png)

    **Source:** [The Decoder](https://the-decoder.com/google-drops-gems-for-skills-joining-openai-and-anthropic-in-the-shift-to-agent-ready-prompt-formats/) | **Categorie:** Outils & Plateformes | **Importance:** must_read

    Google remplace les Gems par des « Skills » dans Gemini : des prompts réutilisables et détaillés qu'on invoque avec « / » ou que le modèle déclenche automatiquement. Le format reprend un standard ouvert d'Anthropic, déjà adopté par OpenAI — les trois grands labs convergent vers des prompts prêts pour les agents. La migration démarre en novembre, avec bascule automatique des Gems existants.
