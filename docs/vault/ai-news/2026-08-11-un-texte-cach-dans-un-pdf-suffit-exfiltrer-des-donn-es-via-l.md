    # Un texte caché dans un PDF suffit à exfiltrer des données via l'agent Rovo d'Atlassian

![Un texte caché dans un PDF suffit à exfiltrer des données via l'agent Rovo d'Atlassian](https://the-decoder.com/wp-content/uploads/2026/08/prompt_inejction_key-1200x670.png)

    **Source:** [The Decoder](https://the-decoder.com/hidden-text-in-a-pdf-is-enough-to-steal-sensitive-data-through-atlassians-ai-agent-rovo/) | **Categorie:** Regulation & Ethique | **Importance:** must_read

    PromptArmor démontre qu'un simple texte caché dans un PDF suffit à détourner Rovo, l'agent IA d'Atlassian, pour exfiltrer silencieusement des données de Jira et Confluence vers un serveur externe. L'attaque ne demande aucune confirmation utilisateur et ne laisse aucune trace. C'est l'archétype de l'injection de prompt indirecte qui menace tout agent branché sur des documents non fiables.
