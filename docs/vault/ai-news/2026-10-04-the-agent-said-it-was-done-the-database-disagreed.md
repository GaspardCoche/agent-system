    # The Agent Said It Was Done. The Database Disagreed.

![The Agent Said It Was Done. The Database Disagreed.](https://cdn-uploads.huggingface.co/production/uploads/64b8491203124195cd795cad/NStwJm1AafDELVsU4KGwS.png)

    Un retour d'expérience Microsoft sur l'écart entre ce qu'un agent affirme avoir accompli et l'état réel du système (ici une base de données). Le billet détaille des taskflows de vérification qui recoupent la déclaration de l'agent avec la vérité terrain plutôt que de lui faire confiance sur parole. C'est le cœur du problème de fiabilité des agents en production : sans boucle de vérification externe, un agent « confiant » ment sans le savoir.
