    # Anthropic annonce une API de détection de watermark pour repérer les textes générés par Claude

![Anthropic annonce une API de détection de watermark pour repérer les textes générés par Claude](https://the-decoder.com/wp-content/uploads/2026/08/anthropic_claude.png)

    **Source:** [The Decoder](https://the-decoder.com/anthropic-announces-watermark-detection-api-that-will-let-third-parties-detect-claudes-ai-texts/) | **Categorie:** Outils & Plateformes | **Importance:** must_read

    Anthropic va proposer une API permettant à des tiers de vérifier si un texte a été écrit par Claude. La technique s'appuie sur la méthode SynthID de Google et ajuste l'aléa lors du choix des mots sans dégrader la qualité, avec des limites reconnues sur les textes très factuels. Un outil de provenance qui va compter pour tous ceux qui produisent du contenu à l'échelle.
