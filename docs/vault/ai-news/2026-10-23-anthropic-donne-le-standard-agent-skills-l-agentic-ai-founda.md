# Anthropic donne le standard Agent Skills à l'Agentic AI Foundation

**Source:** [Simon Willison](https://simonwillison.net/2026/Oct/22/donating-agent-skills/) | **Categorie:** Open Source | **Importance:** must_read

Après le Model Context Protocol, Anthropic donne le standard Agent Skills à l'Agentic AI Foundation (sous la Linux Foundation), co-fondée avec Block et OpenAI. Les Skills deviennent ainsi un format ouvert, neutre et piloté par la communauté, indépendant d'un seul fournisseur. C'est le signal d'une vraie couche standardisée pour packager et partager les compétences d'agents.
