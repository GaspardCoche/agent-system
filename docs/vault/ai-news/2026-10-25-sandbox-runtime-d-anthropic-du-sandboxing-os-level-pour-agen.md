    # sandbox-runtime d'Anthropic : du sandboxing OS-level pour agents IA, sans conteneurs

![sandbox-runtime d'Anthropic : du sandboxing OS-level pour agents IA, sans conteneurs](https://www.marktechpost.com/wp-content/uploads/2026/10/WP-BLOG-BANNER-454-35-scaled.png)

    **Source:** [MarkTechPost](https://www.marktechpost.com/2026/10/24/anthropic-sandbox-runtime-ai-agent-sandbox/) | **Categorie:** Outils & Plateformes | **Importance:** must_read

    Anthropic ouvre sandbox-runtime (srt), le sandbox OS-level qui tourne derrière Claude Code. Il restreint les accès fichiers et réseau des agents, serveurs MCP et outils CLI via Seatbelt sur macOS et bubblewrap sur Linux, sans aucun conteneur. C'est une brique d'isolation directement réutilisable pour sécuriser tes propres agents et MCP servers maison.
